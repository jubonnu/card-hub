# CardHub 公開サイト（利用規約・プライバシーポリシー・サポート）

CardHubアプリの利用規約・プライバシーポリシー・サポートページを提供する静的サイトです。
App Store審査用の公開ページ、およびApp Store Connectへ登録するプライバシーポリシーURLとして使用します。

## 構成

```
legal-site/
  index.html          トップページ（各ページへのリンク）
  terms/index.html     利用規約
  privacy/index.html   プライバシーポリシー
  support/index.html   サポート（お問い合わせ・解約/復元/削除方法等）
  assets/styles.css    共通スタイル（外部CDN不使用、OS標準フォントのみ）
  assets/site.js       目次のスムーズスクロールのみを行う非必須の補助スクリプト
                        （JavaScript無効でも全ページの本文は問題なく読める）
```

## 技術方針

- ビルド不要の素のHTML/CSS/JS。フレームワーク・パッケージ管理は使用しない。
- 外部CDN、外部フォント（Google Fonts等）、Cookie、広告タグ、アクセス解析タグは一切使用しない。
- リンクはすべてルート相対パス（例: `/privacy/`）で記述しており、
  Cloudflare Pagesのディレクトリインデックス解決（`/privacy` → `/privacy/index.html`）により、
  URL末尾のスラッシュの有無に関わらずリンク切れしない。

## 公開前に必ず確認すること（重要）

ブラケット形式のプレースホルダー（`[運営者氏名]`等）は本文からは無くなりましたが、以下はまだ**仮の値**です。production環境へデプロイする前に確認してください。

| 項目 | 現在の値 | 対応が必要な理由 |
|---|---|---|
| 制定日・最終改定日 | 2026年9月3日 | 実際の公開日に更新済み（2026-08-29対応） | privacy/index.html, terms/index.html |
| Cloudflare PagesのURL | `https://cardhub-legal.pages.dev`（`apps/mobile/lib/legalLinks.ts`） | 未デプロイのため想定URL。実際にデプロイして発行されたURLと一致するか確認すること |
| 猶予期間「14日間」 | 14日間（コードのデフォルト値） | 本番環境変数の実値と一致しているか未確認。相違があれば統一すること | privacy/index.html |

合意管轄裁判所は、運営者に有利な条項（自分の所在地の裁判所で対応できる）であるため`terms/index.html`「22. 準拠法・合意管轄」に追記済みです。所在地そのもの（都市名等）は記載せず「当方の所在地を管轄する裁判所」という抽象的な表現にとどめており、運営者の氏名・住所非公開の方針とは矛盾しません。

詳細は `docs/legal-open-questions.md`（リポジトリルート）を参照してください。

### 運営者の氏名・住所について（重要）

方針変更により、運営者の氏名・住所はプライバシーポリシー上に**常時公開しません**。公開表示は
「運営：CardHub運営 ／ 所在国：日本 ／ お問い合わせ：（上記メールアドレス）」に固定し、氏名・住所は
「法令に基づく適法な請求があった場合、本人確認のうえ遅滞なく開示する」旨のみを記載しています。

このため、運営者の実名・住所は**このリポジトリのどのファイルにも保存しないでください**（コード・
コミットメッセージ・issue等を含む）。実際に開示請求へ対応する必要が生じた場合に備えて、氏名・住所は
リポジトリ外の場所（運営者本人のみがアクセスできる手元の記録等）で個別に管理してください。

お問い合わせメールは複数ファイルに埋め込まれているため、変更時は全ファイルへの反映漏れがないか
（`grep -rn "cardhub.official5@gmail.com" legal-site/` 等で）確認してください。将来的にメールアドレスを1箇所で
管理したい場合は、ビルドステップの導入（テンプレート化）を検討してください（本サイトは現時点で
ビルド不要な構成を優先しているため未導入です）。

## Cloudflare Pagesへのデプロイ手順（未実施・手順のみ）

今回のタスクではproductionへのデプロイは行っていません。実際にデプロイする際の手順例:

1. Cloudflareダッシュボードにログインし、「Workers & Pages」→「Pages」から新規プロジェクトを作成する
2. 「直接アップロード」を選択する場合は `legal-site/` ディレクトリ一式をそのままアップロードする
   （Gitリポジトリ連携を使う場合は、ビルドコマンド不要・出力ディレクトリを `legal-site` に設定する）
3. 上記プレースホルダーがすべて置換済みであることを確認する
4. デプロイ後に発行される `*.pages.dev` のURL（または独自ドメインを設定する場合はそのURL）を確認する
5. 発行されたURLを以下へ反映する:
   - App Store Connectの「プライバシーポリシーURL」欄（`/privacy/` ページのURL）
   - CardHubアプリ内の規約・プライバシー・サポートリンク定数（`apps/mobile/lib/legalLinks.ts`）
6. 独自ドメインを使用するかどうかは `docs/legal-open-questions.md` の未確定事項です。使用する場合は
   Cloudflare Pagesのカスタムドメイン設定を別途行ってください。
