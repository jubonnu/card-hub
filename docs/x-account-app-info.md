## 2. コンセプト / 開発背景

> トレカ抽選の「見失い」と「見えない」を解消する。

開発者自身がトレカ抽選への応募に悩んだ経験から、
**「今どこに応募していて、いつ結果が出るのか？」をすぐ見られるようにしたい**という想いで作られたアプリ。

X で使えるストーリーの軸:
- 応募した抽選を忘れる / 締切を見逃す
- 複数店舗に応募すると管理しきれない
- 当選発表日・購入期限まで追いきれない

## 4. 機能一覧

### タブ構成（4つ）
| タブ | 内容 |
|---|---|
| **ホーム** | 「今日やること」（締切・発表・購入期限が近い保存済み抽選を最大3件）＋「新着抽選」 |
| **抽選一覧** | 全国の抽選 / 自分の抽選 の切替、検索、ステータス絞り込み |
| **カレンダー** | 月表示グリッド＋イベント種別の色ドット、日別24時間タイムライン |
| **マイページ** | 今月の実績、各種設定、アカウント操作 |

### 主要機能

**① 抽選を探す**
- 商品名・店舗名でのフリーワード検索
- ステータス絞り込み: すべて / 受付中 / 結果待ち / 受付終了
- 並び順は「締切が近い順」（受付中 → 結果待ち → 受付終了）
- 1ページ10件、「もっと見る」で追加読み込み

**② 自分の抽選として保存**
- ☆ボタンひとつで保存。保存すると自動的に:
  - 通知リマインダーがセットされる
  - iPhoneのカレンダーにも予定が登録される
- 保存を外すと通知・カレンダー予定も自動で削除される

**③ 応募ステータス管理（7段階）**
未設定 → 応募予定 → 応募済み → 当選 / 落選 → 購入済み / 見送り

**④ 通知（リマインダー）**
| 種類 | デフォルト通知タイミング |
|---|---|
| 応募締切 | **3時間前** |
| 当選発表 | **6時間前** |
| 購入期限 | **6時間前** |

- タイミングは 1 / 3 / 6 / 12 時間前・1日前 から選択可能
- **おやすみモード**対応（デフォルト 23:00〜07:00、この時間帯の通知は自動で繰り下げ/繰り上げ）
- すべて**端末内で完結するローカル通知**（サーバーからのプッシュ通知ではない）

**⑤ カレンダー連携**
- アプリ内カレンダー: 月グリッドに3色ドット表示
  - 🟠 応募締切 / 🟣 当選発表 / 🔵 購入期限
  - 日付タップで24時間タイムライン表示
- iPhone標準カレンダー連携: 「CardHub」専用カレンダーを自動作成
  - 予定タイトル例: `【応募締切】商品名`（メモ欄に店舗名）
  - 時刻付きの予定には**60分前アラーム**
  - 時刻が不明なものは**終日予定**として登録
  - 再登録しても重複しない（古い予定を消して作り直す）

**⑥ チェックリスト**
抽選ごとにデフォルト5項目を自動生成:
1. 応募条件を確認
2. 応募を完了する
3. 当選結果を確認
4. 購入手続きをする
5. 受け取り・開封記録

項目の追加・リネーム可、進捗バーで完了率を表示。

**⑦ 商品まとめビュー / フォロー**
同じ商品の抽選を店舗横断でまとめて確認できる。商品単位でフォロー可能。

**⑧ 共有**
抽選詳細から、商品名・店舗・各日時・応募方法・応募URLをまとめたテキストをOS標準の共有機能で送れる。

**⑨ オンボーディング（初回起動時の4スライド）**
1. 🔍 カード抽選をまとめてチェック
2. ☑️ 応募した抽選をしっかり管理
3. 📅 締切・当選発表日をカレンダーで管理
4. 📈 応募履歴から当選率をチェック

## 5. 料金プラン

| プラン | 価格 |
|---|---|
| 無料 | ¥0 |
| プレミアム（月額） | **¥400 / 月（税込）** |
| プレミアム（買い切り） | **¥2,000（一回のみ）** |

**月額と買い切りで使える機能は同じ。**

### 無料でできること（実用機能はすべて無料）
抽選一覧・検索 / 抽選詳細 / 商品まとめビュー / 自分の抽選の保存 /
チェックリスト / **通知リマインダー** / **カレンダー連携** / 商品フォロー / 複数端末同期

### プレミアム限定
**「振り返り・分析」機能のみ**が対象:
- 統計・分析画面（期間切替: 月間 / 3ヶ月 / 年間）
  - 保存数・応募数・当選数・**当選率**
  - 当選率の推移グラフ
  - **店舗別当選率 TOP5**
  - 見送り内訳（応募見送り / 購入見送り）
- マイページ「今月の実績」の応募数・当選数・当選率

> 発信時の訴求軸: 「使う機能は全部無料。プレミアムは自分の抽選傾向を振り返りたい人向け」

## 6. アカウント / プライバシー

- **サインイン不要で使える**（ゲスト利用可）。抽選の閲覧・保存・通知・カレンダーまで全部使える
- サインインは **Sign in with Apple のみ**。目的は複数端末同期
- プレミアム購入時のみサインインが必須
- オフライン対応（変更は復帰時に自動同期）
- アカウント削除は**14日間の猶予期間**あり（その間に再サインインすれば自動で取り消される）

## 7. 投稿ネタになりそうなポイント

- 「応募したの忘れてた」を防ぐ3種類の通知（締切・当選発表・購入期限）
- iPhoneのカレンダーに自動で入るので、普段使いのカレンダーで管理できる
- おやすみモードで深夜に通知が飛ばない
- チェックリストで「応募 → 結果確認 → 購入 → 受け取り」まで追える
- サインイン不要ですぐ使える
- 当選率を店舗別に見られる（プレミアム）

## 9. 既知の仕様上の制約（誇大表現を避けるため）

- 通知はローカル通知のため、**新着抽選の通知は届かない**（保存した抽選のリマインダーのみ）
- 通知の再スケジュールは通知設定画面を開いたときに実行される
- 地域での絞り込みはUI未実装（データとしては保持している）
- フォロー中商品の取得は上限100件
- iPhoneのカレンダー側で予定を手動削除しても、アプリ側には反映されない（アプリ内の表示は保存済み抽選から計算しているため影響なし）
